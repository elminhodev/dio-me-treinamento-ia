# Segundo Cérebro com IA — Análise Fundamentalista e Valuation

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio prático de Inteligência Artificial Generativa. O objetivo é criar um segundo cérebro utilizando o Gemini Notebook (NotebookLM), capaz de auxiliar nos estudos sobre análise fundamentalista, valuation e metodologias de investimento.

A proposta é utilizar fontes confiáveis para organizar conhecimentos, esclarecer conceitos financeiros e comparar diferentes métodos de avaliação de empresas, utilizando a IA como ferramenta de aprendizado.

## 🎯 Objetivo

Criar um assistente de estudos com IA capaz de explicar os fundamentos da análise de empresas, ensinar métodos de valuation, comparar estratégias de investimento e responder perguntas com base em fontes confiáveis, sempre indicando as referências utilizadas.
